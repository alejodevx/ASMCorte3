# Termómetro de la Tierra — React Starter

No requiere Python.

```bash
npm install
npm run dev
```

Abra la dirección que muestre Vite (normalmente `http://localhost:5173`).

El starter deja resueltos: carga del CSV, parseo mensual, línea base 1880–1900, filtro desde 1926, selector temporal, ventanas de 12 meses y gráfica base.

El trabajo restante del equipo es diseñar la representación artística y la sonificación.
